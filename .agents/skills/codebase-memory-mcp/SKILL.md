# Codebase Memory MCP Skill

## Overview
`codebase-memory-mcp` is a zero-dependency C-based AST and hybrid LSP knowledge graph indexing engine installed locally at `C:\Users\Nilesh\.local\bin\codebase-memory-mcp.exe`.

## Key Capabilities
1. **Tree-Sitter AST Indexing**: Indexes functions, classes, methods, imports, and cross-file dependencies across 158 languages in milliseconds.
2. **3D Knowledge Graph Visualization**: Interactive graph UI served locally at `http://localhost:9749`.
3. **Symbol Dependency Tracing**: High-speed call chain tracing, HTTP route linking, and structural impact analysis.
4. **Persistent Workspace Memory**: Stores indexed project nodes and architectural decisions across sessions.
